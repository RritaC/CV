# Portfolio cover images (optional)

The portfolio page shows a **screenshot of each website** as the card cover using a free screenshot service (Thum.io). If a screenshot fails to load (e.g. rate limit or the service is down), the project name is shown instead.

## Using your own screenshots

To use your own cover images instead of the live screenshot API:

1. Take a screenshot of each site (e.g. browser “Capture full page” or a tool like [GoFullPage](https://chrome.google.com/webstore) / [FireShot](https://getfireshot.com/)).
2. Save them in this folder with these exact names (JPG or PNG):
   - `1-dardex.jpg`
   - `2-primex.jpg`
   - `3-mendex.jpg`
   - `4-institute-of-making.jpg`
   - `5-astrachat.jpg`
   - `6-klubi-matikes.jpg`
   - `7-crypto-project.jpg`
   - `8-been-kosova.jpg`
   - `9-rise.jpg`
   - `10-beauty-for-all.jpg`
3. In `portfolio.html`, change each card’s cover from the Thum.io URL to the local path, e.g.  
   `src="portfolio-covers/1-dardex.jpg"`  
   (Replace the existing `src` on the `.portfolio-cover-img` in that card.)

Recommended size: about 640px wide (or 1280px for retina). Aspect ratio 16∶10 fits the card best.
